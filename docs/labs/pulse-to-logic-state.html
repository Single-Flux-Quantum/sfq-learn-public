Without skew: every intended 1 lands in-window; every intended 0 stays empty → 0% timing errors. With skew: some pulses arrive early/late. The receiver still looks only inside the window, so the decoded bit can disagree with Alice’s intent — the RSFQ analogue of “wrong basis / wrong epoch.”
